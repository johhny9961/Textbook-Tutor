Purpose & context Jerald is a college student preparing for the OAT (Optometry Admission Test), which is the decisive factor for admission to his target optometry school. He has roughly 12–14 months before the exam and studies in fragmented ~20-minute sessions due to a demanding schedule. He describes himself as neurodivergent and "nerd averse" — traditional tools like Anki haven't worked for him. The stakes are high: a poor score means an additional year of schooling, and he treats this as a one-shot opportunity. The OAT subjects he cannot cover through coursework alone are Organic Chemistry and Quantitative Reasoning (no calculus required). His broader strategy is to use the OAT Engine to build foundational knowledge so he can then use commercial OAT prep apps that assume prerequisite knowledge. This is Jerald's first software project of this kind. He has a friend reviewing the codebase on GitHub and has expressed genuine enthusiasm for the build process, hitting usage limits multiple times in single sessions. --- Current state Jerald has built and deployed a PWA called the OAT Engine — a spaced repetition system (SRS) with a four-phase learning progression: Worked example (with self-explanation) Faded completion Stepwise retrieval Full problem The app is deployed on GitHub Pages (oat-mobile-deployment branch), with the Claude artifact version preserved on main. It runs on his phone via the DuckDuckGo browser (chosen to avoid localStorage wipes from Vanadium's browsing data clearing). GrapheneOS/Vanadium is used for general browsing. Recently completed features: Study by Topic, Search (with mode toggles and grouped results), Practice Mode (SRS-write-protected), Session History, and Skip Button. The service worker cache is at oat-engine-v3. Active challenge: The content pipeline is the core bottleneck — generating problem sets requires hours of manual labor, making the tool a "nice to have on a shelf" rather than an active study resource. This is the problem Jerald is actively trying to solve. In scoping: A "talking textbook" module that integrates OpenStax textbook content (CC BY licensed, API-accessible) with the OAT Engine's phase logic. The current leading approach uses existing OpenStax end-of-chapter questions as the problem base, with the relevant textbook section rendered inline as a reference panel when Jerald is stuck — explicitly not a link-out, because context-switching kills his workflow. iDoRecall was surfaced as a potential content base (OpenStax-linked flashcard sets) that could be layered with OAT Engine's phase logic to reduce build scope. No final decision reached; still in scoping mode. --- On the horizon Bookmark/Flag feature (next planned): A flagged object in state keyed by problem ID, persisted to its own localStorage key, included in export. Toggle buttons on study screen and search results. Home screen entry point launching a practice session of all flagged problems. Talking textbook / OpenStax integration — decision pending on scope and whether to build from scratch or layer onto iDoRecall's content base. Deferred features (stabilize-first decision): Dynamic problem generation based on weakness detection; Phase 3 wrong-answer text box for targeted LLM explanations; ADHD friction passes 8–10. Content to generate: More chemistry problem packs (currently has SN1/SN2/E1/E2, Oxidation, Reduction, Balancing Equations, Naming Acids, and a Chemistry 1210 pack covering molecular polarity and geometry). --- Key learnings & principles Content bottleneck is the load-bearing problem. The engine's value is zero if content generation requires hours of manual work per topic. Architecture decisions should be evaluated against whether they reduce this friction. Context-switching is a dropout risk. Features that require leaving the app (link-outs, external tools) will not get used. Everything that matters must be inline. Getting stuck without help is the primary dropout risk given Jerald's learning profile — this is why the "explain" button was pulled forward from a later layer to an earlier one. Stability before features. Jerald explicitly decided to stabilize and use the current build before adding new features, and prefers real usage data over UX polish guesses. Baby steps for architectural changes. Scoped, isolated changes over rewrites. One bug per pass, test between passes, ranked by blast radius. Additive over refactoring. Given the codebase's complexity ("vibe coded"), all additions should be additive rather than touching existing logic. Pedagogical quality is separate from engineering. The validator catches structural errors; content review is a distinct concern. --- Approach & patterns Iterative, test-between-passes workflow: Requests architectural explanations before implementation, asks for bug reviews after each change, prefers testing between features rather than batching. Explicit plan before code: Asks Claude to explain the plan before coding each new feature; asks for features ranked by invasiveness. Stream-of-consciousness communication style: Often archives thoughts mid-session without requiring action. Claude should not treat every statement as an action item. Direct execution preference: When Jerald says he knows what he wants, he means it — over-asking clarifying questions is a flagged anti-pattern. Claude was explicitly corrected for this more than once. Prompt quality awareness: Jerald uses a PQ (prompt quality) scoring system and values tight, constrained requests with explicit deliverables and next steps. He also correctly noted the "stepwise exception": when someone lacks context on what a task means, they can't be expected to define outcome and next steps upfront. Behavioral audit interest: Jerald has attempted to audit his own learning behavior patterns across conversations (passive vs. active problem-solving), suggesting metacognitive awareness of his study habits. --- Tools & resources OAT Engine: Custom PWA (React, single HTML file + sw.js + manifest), deployed on GitHub Pages Storage: Browser localStorage; export via copyable textarea (Blob/download doesn't work in artifact sandbox) LLM explain feature: API-key-agnostic, key stored on-device, routed through configurable proxy URL Device/browser: GrapheneOS, Vanadium (general), DuckDuckGo browser (PWA) Content generation: Microsoft Copilot for structuring textbook content; Claude for verification and JSON generation Content format: JSON problem packs with conceptId-linked phase gating Textbook source under evaluation: OpenStax (CC BY, API-accessible); iDoRecall as potential content base Version control: GitHub (main = Claude artifact version; oat-mobile-deployment = PWA)

const calcNewInterval = (oldInterval, correct, phase) => {
  const boost = CONFIG.PHASE_INTERVAL_BOOST[phase] || 1.0;
  if (correct) {
    return Math.min(oldInterval * CONFIG.CORRECT_MULTIPLIER * boost, CONFIG.MAX_INTERVAL);

};

const formatTime = (s) => {
  const m = Math.floor(s / 60);
  const sec = s % 60;
  return `${m}:${sec.toString().padStart(2, "0")}`;
};

const median = (arr) => {
  if (!arr.length) return 0;
  const sorted = [...arr].sort((a, b) => a - b);
  const mid = Math.floor(sorted.length / 2);
  return sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
};

  PROGRESS: "oat-progress",
  HEATMAP: "oat-heatmap",
  SESSION_LOG: "oat-sessions",
  SETTINGS: "oat-settings",
  USER_CONTENT: "oat-user-content",
};

const storage = {
  async save(key, data) {
    try {
      localStorage.setItem(key, JSON.stringify(data));
      return true;
    } catch (e) {
      console.error(`Save failed [${key}]:`, e);
      return false;
    }
  },
  async load(key, fallback) {
    try {
      const raw = localStorage.getItem(key);
      if (raw !== null) return JSON.parse(raw);
    } catch (e) {
      // parse failed
    }
    return fallback;
  },
  async exportAll() {
    const progress = await storage.load(STORAGE_KEYS.PROGRESS, {});
    const heatmap = await storage.load(STORAGE_KEYS.HEATMAP, {});
    const sessionLog = await storage.load(STORAGE_KEYS.SESSION_LOG, []);
    const userContent = await storage.load(STORAGE_KEYS.USER_CONTENT, []);
    return { progress, heatmap, sessionLog, userContent, exportedAt: new Date().toISOString(), version: 2 };
  }
};

// Migrate from v1 single-key storage
async function migrateFromV1() {
  try {
    const raw = localStorage.getItem("oat-engine-state");
    if (raw) {
      const data = JSON.parse(raw);
      if (data.progress) await storage.save(STORAGE_KEYS.PROGRESS, data.progress);
      if (data.heatmap) await storage.save(STORAGE_KEYS.HEATMAP, data.heatmap);
      if (data.sessionLog) await storage.save(STORAGE_KEYS.SESSION_LOG, data.sessionLog);
      localStorage.removeItem("oat-engine-state");
      console.log("Migrated from v1 storage");
    }
  } catch (e) {
    // No v1 data, that's fine
  }
}

// ─── CONTENT VALIDATION ──────────────────────────────────────────────────────

const REQUIRED_FIELDS = ["id", "topic", "subtopic", "conceptId", "subject", "phase", "difficulty", "problem_text", "steps", "answer", "explanation"];
const VALID_PHASES = [1, 2, 3, 4];
const VALID_DIFFICULTIES = [1, 2, 3, 4, 5];

function validateProblems(jsonText) {
  const errors = [];
  let parsed;

  // Step 1: Parse JSON
  try {
    parsed = JSON.parse(jsonText);
  } catch (e) {
    // Give a human-readable parse error
    const match = e.message.match(/position\s+(\d+)/i);
    if (match) {
      const pos = parseInt(match[1]);
      const before = jsonText.substring(Math.max(0, pos - 40), pos);
      const after = jsonText.substring(pos, pos + 20);
      errors.push(`The JSON has a syntax error near: "...${before}⚠️${after}..." — check for missing commas, extra commas, or mismatched brackets around that spot.`);
    } else {
      errors.push("The text you pasted isn't valid JSON. Make sure it starts with [ and ends with ], and that every string is in double quotes.");
    }
    return { valid: false, errors, problems: [] };
  }

  // Step 2: Must be an array
  if (!Array.isArray(parsed)) {
    errors.push("The JSON must be an array of problems — it should start with [ and end with ]. You pasted something else (maybe a single object without the brackets?).");
    return { valid: false, errors, problems: [] };
  }

  if (parsed.length === 0) {
    errors.push("The array is empty — no problems found.");
    return { valid: false, errors, problems: [] };
  }

  // Step 3: Validate each problem
  const seenIds = new Set();

  for (let i = 0; i < parsed.length; i++) {
    const p = parsed[i];
    const label = p.id ? `Problem ${i + 1} ('${p.id}')` : `Problem ${i + 1}`;

    if (typeof p !== "object" || p === null || Array.isArray(p)) {
      errors.push(`${label} isn't an object — each problem needs to be wrapped in { }.`);
      continue;
    }

    // Check required fields
    for (const field of REQUIRED_FIELDS) {
      if (p[field] === undefined || p[field] === null) {
        errors.push(`${label} is missing the '${field}' field.`);
      }
    }

    // Check types and ranges
    if (p.id !== undefined) {
      if (typeof p.id !== "string" || p.id.trim() === "") {
        errors.push(`${label}: 'id' must be a non-empty text string.`);
      } else if (seenIds.has(p.id)) {
        errors.push(`${label}: duplicate id — '${p.id}' already appeared earlier in this set.`);
      } else {
        seenIds.add(p.id);
      }
    }

    if (p.phase !== undefined && !VALID_PHASES.includes(p.phase)) {
      errors.push(`${label}: 'phase' must be 1, 2, 3, or 4. You have ${JSON.stringify(p.phase)}.`);
    }

    if (p.difficulty !== undefined && !VALID_DIFFICULTIES.includes(p.difficulty)) {
      errors.push(`${label}: 'difficulty' must be 1-5. You have ${JSON.stringify(p.difficulty)}.`);
    }

    if (p.subject !== undefined && (typeof p.subject !== "string" || p.subject.trim() === "")) {
      errors.push(`${label}: 'subject' must be a non-empty text string (e.g., "ochem", "trig", "anatomy").`);
    }

    // Check string fields
    for (const sf of ["topic", "subtopic", "conceptId", "subject", "problem_text", "answer", "explanation"]) {
      if (p[sf] !== undefined && typeof p[sf] !== "string") {
        errors.push(`${label}: '${sf}' must be a text string.`);
      }
    }

    // Check steps array
    if (p.steps !== undefined) {
      if (!Array.isArray(p.steps)) {
        errors.push(`${label}: 'steps' must be an array (even if empty — use [] for phase 4 problems).`);
      } else {
        for (let si = 0; si < p.steps.length; si++) {
          const step = p.steps[si];
          const stepLabel = `${label}, step ${si + 1}`;
          if (typeof step !== "object" || step === null) {
            errors.push(`${stepLabel}: each step must be an object with 'text' and 'hidden'.`);
            continue;
          }
          if (typeof step.text !== "string") {
            errors.push(`${stepLabel}: missing or invalid 'text' field.`);
          }
          if (typeof step.hidden !== "boolean") {
            errors.push(`${stepLabel}: 'hidden' must be true or false (no quotes).`);
          }
          if (step.hidden === true && (typeof step.reveal_text !== "string" || step.reveal_text.trim() === "")) {
            errors.push(`${stepLabel}: hidden steps must have a 'reveal_text' field (the text shown when the user reveals it).`);
          }
        }
      }
    }

    // Check optional fields (phase 1 only)
    if (p.phase !== 1) {
      if (p.self_explanation !== undefined || p.self_explanation_answer !== undefined) {
        // Not an error, just a note — we'll allow it but it won't be shown
      }
    }
  }

  return {
    valid: errors.length === 0,
    errors,
    problems: errors.length === 0 ? parsed : []
  };
}

function getContentSummary(problems) {
  const summary = {};
  for (const p of problems) {
    const key = p.topic || "Unknown";
    if (!summary[key]) {
      summary[key] = { topic: key, subject: p.subject, phases: { 1: 0, 2: 0, 3: 0, 4: 0 }, total: 0 };
    }
    summary[key].phases[p.phase] = (summary[key].phases[p.phase] || 0) + 1;
    summary[key].total++;
  }
  return Object.values(summary);
}

  // Practice mode state
  const [practiceMode, setPracticeMode] = useState(false);

  const [practiceReturnScreen, setPracticeReturnScreen] = useState("home"); // where to go back

  const timerRef = useRef(null);

      if (settings.proxyUrl) setProxyUrl(settings.proxyUrl);
      // Find last session timestamp for bridge screen

        setLastSessionTimestamp(sLog[sLog.length - 1].timestamp);
      }

      console.error("loadAll failed, starting fresh:", e);
      setUserContent(DEFAULT_CONTENT);
    }
    setLoaded(true);
  }, []);

  useEffect(() => { loadAll(); }, [loadAll]);

  // ─── PHASE GATING ──────────────────────────────────────────────────────
  // A problem at phase N is only available if the learner has met the gate
  // threshold on the same conceptId at phase N-1.

  const isPhaseUnlocked = useCallback((problem) => {
    if (problem.phase <= 1) return true;
    const prevPhaseProblems = problems.filter(
      p => p.conceptId === problem.conceptId && p.phase === problem.phase - 1
    );
    if (prevPhaseProblems.length === 0) return true; // no prerequisite exists
    // Check if ANY prev-phase problem for this concept meets the gate
    return prevPhaseProblems.some(pp => {
      const prog = progress[pp.id];
      if (!prog) return false;
      // Phase 1 prereqs: studied enough times (no accuracy — there's nothing to grade)
      if (pp.phase === 1) {
        return (prog.studied || 0) >= CONFIG.PHASE_GATE_MIN_ATTEMPTS;
      }
      return prog.attempts >= CONFIG.PHASE_GATE_MIN_ATTEMPTS &&
             prog.accuracy >= CONFIG.PHASE_GATE_ACCURACY;
    });
  }, [problems, progress]);

  // ─── SCHEDULING ENGINE ─────────────────────────────────────────────────

  const getDueProblems = useCallback((subjectFilter = "all", modeFilter = "full", topicFilter = "all") => {
    const currentTime = now();
    const due = [];
    const unseen = [];

    for (const p of problems) {
      // Subject filter
      if (subjectFilter !== "all" && p.subject !== subjectFilter) continue;
      // Topic filter
      if (topicFilter !== "all" && p.topic !== topicFilter) continue;
      // Quick mode: only serve phase 1-2, difficulty 1-2
      if (modeFilter === "quick" && (p.phase > 2 || p.difficulty > 2)) continue;
      // Phase gating
      if (!isPhaseUnlocked(p)) continue;

      const prog = progress[p.id];
      if (!prog) {
        unseen.push(p);
      } else if (prog.nextDue <= currentTime) {
        due.push({ ...p, overdue: currentTime - prog.nextDue });
      }
    }

    due.sort((a, b) => b.overdue - a.overdue);
    unseen.sort((a, b) => a.phase - b.phase || a.difficulty - b.difficulty);

    return { due, unseen };
  }, [problems, progress, isPhaseUnlocked]);

  // ─── SMART PROBLEM SELECTOR ────────────────────────────────────────────
  // Replaces the old FIFO queue. Handles:
  //   - Interleaving (topic cooldown)
  //   - Difficulty calibration (rolling accuracy)
  //   - Warm-up (first 2 problems are easier)
  //   - End-on-success (last problem before timer is easy)
  //   - Fatigue detection (response time)

  const getNextProblem = useCallback((opts = {}) => {
    const { warmup = false, endOnSuccess = false, subjectOverride, modeOverride, topicOverride } = opts;
    const { due, unseen } = getDueProblems(subjectOverride || sessionSubject, modeOverride || sessionMode, topicOverride || sessionTopic);
    const pool = [...due, ...unseen];

    if (pool.length === 0) return null;

    // Calculate current rolling accuracy
    const rollingPct = rollingAccuracy.length > 0
      ? rollingAccuracy.reduce((a, b) => a + b, 0) / rollingAccuracy.length
      : 1.0;

    // Determine target difficulty range based on rolling accuracy
    let maxDifficulty = 5;
    let preferLowDifficulty = false;

    if (warmup || endOnSuccess) {
      maxDifficulty = 2;
      preferLowDifficulty = true;
    } else if (rollingPct < 0.5) {
      // Below 50%: drop to worked examples
      maxDifficulty = 2;
      preferLowDifficulty = true;
    } else if (rollingPct < 0.75 || consecutiveErrors >= CONFIG.CONSECUTIVE_ERROR_TRIGGER) {
      // Below 75% or 2+ consecutive errors: ease up
      maxDifficulty = 3;
      preferLowDifficulty = true;
    } else if (rollingPct > CONFIG.OPTIMAL_ACCURACY_MAX) {
      // Above 95%: push harder
      preferLowDifficulty = false;
    }

    // Check for fatigue via response time
    if (sessionProblems.length > 0) {
      const lastRT = sessionProblems[sessionProblems.length - 1]?.responseTime;
      const recentRTs = sessionProblems.map(sp => sp.responseTime).filter(Boolean);
      const medRT = median(recentRTs);
      if (lastRT && medRT && lastRT > medRT * CONFIG.FATIGUE_RT_MULTIPLIER) {
        maxDifficulty = Math.min(maxDifficulty, 3);
        preferLowDifficulty = true;
      }
    }

    // Filter pool by difficulty
    let candidates = pool.filter(p => p.difficulty <= maxDifficulty);
    if (candidates.length === 0) candidates = pool; // fallback

    // Interleaving: deprioritize recently shown topics
    const cooldownTopics = recentTopics.slice(-CONFIG.TOPIC_COOLDOWN);
    const fresh = candidates.filter(p => !cooldownTopics.includes(p.topic));
    if (fresh.length > 0) candidates = fresh;

    // Sort: prefer due over unseen, then by overdue amount / phase order
    candidates.sort((a, b) => {
      const aIsDue = a.overdue !== undefined;
      const bIsDue = b.overdue !== undefined;
      if (aIsDue && !bIsDue) return -1;
      if (!aIsDue && bIsDue) return 1;
      if (aIsDue && bIsDue) return b.overdue - a.overdue;
      // Both unseen: lower phase first, then lower difficulty
      if (preferLowDifficulty) return a.difficulty - b.difficulty || a.phase - b.phase;
      return a.phase - b.phase || a.difficulty - b.difficulty;
    });

    return candidates[0] || null;
  }, [getDueProblems, sessionSubject, sessionTopic, sessionMode, rollingAccuracy, consecutiveErrors, recentTopics, sessionProblems]);

  // ─── STATS ─────────────────────────────────────────────────────────────

  const getStats = useCallback((subjectFilter = "all") => {
    const filtered = subjectFilter === "all" ? problems : problems.filter(p => p.subject === subjectFilter);
    const total = filtered.length;
    const seen = filtered.filter(p => progress[p.id]).length;
    const mastered = filtered.filter(p => {
      const prog = progress[p.id];
      if (!prog) return false;
      // Mastery: phase 3+ problem, 5+ attempts, last 3 correct
      const isAdvanced = p.phase >= CONFIG.MASTERY_MIN_PHASE;
      const enoughAttempts = prog.attempts >= CONFIG.MASTERY_MIN_ATTEMPTS;
      const recentAllCorrect = (prog.recentResults || []).slice(-CONFIG.MASTERY_RECENT_CORRECT)
        .every(r => r === true) && (prog.recentResults || []).length >= CONFIG.MASTERY_RECENT_CORRECT;
      return isAdvanced && enoughAttempts && recentAllCorrect;
    }).length;
    const { due } = getDueProblems(subjectFilter);
    return { total, seen, mastered, dueCount: due.length };
  }, [problems, progress, getDueProblems]);

  const getTopicStats = useCallback((subjectFilter = "all") => {
    const filtered = subjectFilter === "all" ? problems : problems.filter(p => p.subject === subjectFilter);
    const topics = {};
    for (const p of filtered) {
      if (!topics[p.topic]) {
        topics[p.topic] = { topic: p.topic, subject: p.subject, total: 0, seen: 0, due: 0, avgAccuracy: 0, accuracySum: 0, accuracyCount: 0 };
      }
      const t = topics[p.topic];
      t.total++;
      const prog = progress[p.id];
      if (prog) {
        t.seen++;
        // Only count graded phases (2+) in accuracy — Phase 1 is studied, not tested
        if (p.phase > 1 && prog.attempts > 0) {
          t.accuracySum += prog.accuracy;
          t.accuracyCount++;
        }
        if (prog.nextDue <= now()) t.due++;
      }
    }
    return Object.values(topics).map(t => ({
      ...t,
      avgAccuracy: t.accuracyCount > 0 ? Math.round((t.accuracySum / t.accuracyCount) * 100) : null
    }));
  }, [problems, progress]);

  // ─── SESSION MANAGEMENT ────────────────────────────────────────────────

  const startSession = (mode, subject = "all", topic = "all") => {
    setNoProblemsMsg(""); // clear any previous message
    // Check for bridge screen (long absence)
    const gap = lastSessionTimestamp ? now() - lastSessionTimestamp : 0;
    if (gap > 7 * 24 * 60 * 60 * 1000) { // > 1 week
      setSessionMode(mode);
      setSessionSubject(subject);
      setSessionTopic(topic);
      setScreen("bridge");
      return;
    }

    launchSession(mode, subject, topic);
  };

  const launchSession = (mode, subject, topic = "all") => {
    // Check for available problems BEFORE mutating session state
    const next = getNextProblem({ warmup: true, subjectOverride: subject, modeOverride: mode, topicOverride: topic });
    if (!next) {
      const label = subject === "all" ? "" : ` for ${subject}`;
      const topicLabel = topic !== "all" ? ` → ${topic}` : "";
      const modeLabel = mode === "quick" ? " in quick mode (Phases 1–2)" : mode === "pomodoro" ? " in deep study mode" : "";
      setNoProblemsMsg(`Nothing due${label}${topicLabel}${modeLabel} right now. Try a different filter or come back later.`);
      return;
    }

    setNoProblemsMsg("");
    setSessionMode(mode);
    setSessionSubject(subject);
    setSessionTopic(topic);
    const duration = mode === "quick" ? CONFIG.QUICK_SESSION : mode === "pomodoro" ? CONFIG.POMODORO_SESSION : CONFIG.FULL_SESSION;
    setSessionTimer(duration);
    setSessionStartTime(now());
    setSessionProblems([]);
    setConsecutiveErrors(0);
    setRollingAccuracy([]);
    setRecentTopics([]);
    setTimerExpired(false);

    setCurrentProblem(next);
    setProblemStartTime(now());
    resetProblemUI();
    setRecentTopics([next.topic]);
    setScreen("study");
  };

  // ─── PRACTICE MODE ──────────────────────────────────────────────────────

  const launchPractice = (problemList, returnScreen = "home") => {
    if (problemList.length === 0) return;
    // Shuffle
    const shuffled = [...problemList];
    for (let i = shuffled.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
    }
    setPracticeMode(true);
    setPracticeQueue(shuffled);
    setPracticeIndex(0);
    setPracticeReturnScreen(returnScreen);
    setCurrentProblem(shuffled[0]);
    setProblemStartTime(now());
    resetProblemUI();
    setScreen("study");
  };

  // Timer: counts down but does NOT auto-end
  useEffect(() => {
    if (screen !== "study") return;
    timerRef.current = setInterval(() => {
      setSessionTimer(prev => {
        if (prev <= 1) {
          clearInterval(timerRef.current);
          setTimerExpired(true);
          return 0;
        }
        return prev - 1;
      });
    }, 1000);
    return () => clearInterval(timerRef.current);
  }, [screen]);

  const endSession = () => {
    // Practice mode: clean exit, no logging
    if (practiceMode) {
      setPracticeMode(false);
      setScreen(practiceReturnScreen);
      return;
    }
    clearInterval(timerRef.current);
    if (sessionProblems.length === 0) {
      setSessionTopic("all"); // reset even on early exit
      setScreen("home");
      return;
    }
    const elapsed = sessionStartTime ? Math.round((now() - sessionStartTime) / 1000) : 0;
    const correct = sessionProblems.filter(p => p.correct).length;
    const total = sessionProblems.length;

    const todayStr = dayKey();
    const newHeatmap = { ...heatmap, [todayStr]: (heatmap[todayStr] || 0) + total };
    setHeatmap(newHeatmap);
    saveHeatmap(newHeatmap);

    const logEntry = { date: todayStr, elapsed, correct, total, timestamp: now() };
    const newLog = [...sessionLog, logEntry].slice(-500); // keep last 500 sessions
    setSessionLog(newLog);
    saveSessionLog(newLog);
    setLastSessionTimestamp(now());
    setSessionTopic("all"); // reset topic filter for next session

    setScreen("summary");
  };

  // ─── PROBLEM INTERACTION ───────────────────────────────────────────────

  const resetProblemUI = () => {
    setRevealedSteps(0);
    setUserAnswer("");
    setShowAnswer(false);
    setShowSelfExplanation(false);
    setSelfExplanationRevealed(false);
    setProblemGraded(false);
    setExplainText("");
    setExplainLoading(false);
    setExplainError("");
  };

  const recordAnswer = (correct) => {
    // Practice mode: reveal answer but don't touch SRS
    if (practiceMode) {
      setProblemGraded(true);
      setShowAnswer(true);
      return;
    }
    const responseTime = now() - problemStartTime;
    const problemId = currentProblem.id;

    const prev = progress[problemId] || {
      attempts: 0, correct: 0, accuracy: 0,
      interval: CONFIG.INITIAL_INTERVAL,
      responseTimes: [], recentResults: []
    };
    const newAttempts = prev.attempts + 1;
    const newCorrect = prev.correct + (correct ? 1 : 0);
    const newAccuracy = newCorrect / newAttempts;
    const newInterval = calcNewInterval(
      prev.interval || CONFIG.INITIAL_INTERVAL,
      correct,
      currentProblem.phase
    );
    const newResponseTimes = [...(prev.responseTimes || []).slice(-9), responseTime];
    const newRecentResults = [...(prev.recentResults || []).slice(-9), correct];

    const newProgress = {
      ...progress,
      [problemId]: {
        attempts: newAttempts,
        correct: newCorrect,
        accuracy: newAccuracy,
        interval: newInterval,
        nextDue: now() + newInterval,
        responseTimes: newResponseTimes,
        recentResults: newRecentResults,
        lastSeen: now(),
        lastPhase: currentProblem.phase
      }
    };
    setProgress(newProgress);
    saveProgress(newProgress);

    // Session tracking
    const newSessionProblems = [...sessionProblems, { id: problemId, correct, responseTime, topic: currentProblem.topic }];
    setSessionProblems(newSessionProblems);

    // Consecutive errors
    if (!correct) {
      setConsecutiveErrors(prev => prev + 1);
    } else {
      setConsecutiveErrors(0);
    }

    // Rolling accuracy
    const newRolling = [...rollingAccuracy.slice(-(CONFIG.ROLLING_WINDOW - 1)), correct ? 1 : 0];
    setRollingAccuracy(newRolling);

    setProblemGraded(true);
    setShowAnswer(true);
  };

  // Phase 1 only: record that the worked example was studied.
  // Advances SRS schedule but does NOT touch accuracy, rolling window,
  // or consecutive error tracking. Prevents Phase 1 from inflating
  // every downstream metric that reads accuracy data.
  const recordStudied = () => {
    // Practice mode: reveal answer but don't touch SRS
    if (practiceMode) {
      setShowAnswer(true);
      return;
    }
    const problemId = currentProblem.id;
    const prev = progress[problemId] || {
      attempts: 0, correct: 0, accuracy: 0,
      interval: CONFIG.INITIAL_INTERVAL,
      responseTimes: [], recentResults: [],
      studied: 0
    };

    const newInterval = calcNewInterval(
      prev.interval || CONFIG.INITIAL_INTERVAL,
      true,
      currentProblem.phase
    );

    const newProgress = {
      ...progress,
      [problemId]: {
        ...prev,
        studied: (prev.studied || 0) + 1,
        interval: newInterval,
        nextDue: now() + newInterval,
        lastSeen: now(),
        lastPhase: currentProblem.phase
      }
    };
    setProgress(newProgress);
    saveProgress(newProgress);

    const newSessionProblems = [...sessionProblems, {
      id: problemId, correct: true, studied: true,
      responseTime: now() - problemStartTime, topic: currentProblem.topic
    }];
    setSessionProblems(newSessionProblems);

    setShowAnswer(true);
  };

  const nextProblem = () => {
    // Practice mode: advance queue or exit
    if (practiceMode) {
      const nextIdx = practiceIndex + 1;
      if (nextIdx >= practiceQueue.length) {
        setPracticeMode(false);
        setScreen(practiceReturnScreen);
        return;
      }
      setPracticeIndex(nextIdx);
      setCurrentProblem(practiceQueue[nextIdx]);
      setProblemStartTime(now());
      resetProblemUI();
      return;
    }
    // Check session end conditions
    const problemCount = sessionProblems.length;

    // If timer expired, end after this problem (soft end — we let them finish)
    if (timerExpired) {
      endSession();
      return;
    }

    // Hard cap
    if (problemCount >= CONFIG.MAX_PROBLEMS_PER_SESSION) {
      endSession();
      return;
    }

    // Is this nearing the end? Try to end on a success
    const nearEnd = sessionTimer <= 120 || problemCount >= CONFIG.MAX_PROBLEMS_PER_SESSION - 2;
    const lastWasError = sessionProblems.length > 0 && !sessionProblems[sessionProblems.length - 1].correct;

    const next = getNextProblem({
      warmup: problemCount < 2, // first 2 are warm-up
      endOnSuccess: nearEnd && lastWasError
    });

    if (!next) {
      endSession();
      return;
    }

    setCurrentProblem(next);
    setProblemStartTime(now());
    resetProblemUI();
    setRecentTopics(prev => [...prev, next.topic]);
  };

  const skipProblem = () => {
    // Practice mode: advance queue, no recording
    if (practiceMode) {
      const nextIdx = practiceIndex + 1;
      if (nextIdx >= practiceQueue.length) {
        setPracticeMode(false);
        setScreen(practiceReturnScreen);
        return;
      }
      setPracticeIndex(nextIdx);
      setCurrentProblem(practiceQueue[nextIdx]);
      setProblemStartTime(now());
      resetProblemUI();
      return;
    }
    // Normal mode: skip without recording, still respect session limits
    if (timerExpired) {
      endSession();
      return;
    }
    const next = getNextProblem();
    if (!next) {
      endSession();
      return;
    }
    setCurrentProblem(next);
    setProblemStartTime(now());
    resetProblemUI();
    setRecentTopics(prev => [...prev, next.topic]);
  };

  // ─── RENDER HELPERS ────────────────────────────────────────────────────

  const getRollingAccuracyPct = () => {
    if (rollingAccuracy.length === 0) return null;
    return Math.round((rollingAccuracy.reduce((a, b) => a + b, 0) / rollingAccuracy.length) * 100);
  };

  const renderHeatmap = () => {
    const today = new Date();
    const totalDays = CONFIG.HEATMAP_WEEKS * 7;
    const cells = [];
    for (let i = totalDays - 1; i >= 0; i--) {
      const d = new Date(today);
      d.setDate(d.getDate() - i);
      const key = dayKey(d);
      const count = heatmap[key] || 0;
      const intensity = count === 0 ? 0 : count < 5 ? 1 : count < 10 ? 2 : count < 20 ? 3 : 4;
      cells.push(
        <div
          key={key}
          title={`${key}: ${count} problems`}
          style={{
            width: 10, height: 10, borderRadius: 2,
            background: intensity === 0 ? "#2a2a2e" : intensity === 1 ? "#1a4a3a" : intensity === 2 ? "#1a6a4a" : intensity === 3 ? "#1a9a6a" : "#1aca8a",
            border: key === dayKey() ? "1px solid #5ae4a8" : "1px solid transparent"
          }}
        />
      );
    }
    return cells;
  };

  const renderExplainButton = (isPhase1 = false) => {
    const hasApi = apiKey && proxyUrl;
    const btnLabel = isPhase1
      ? (hasApi ? "Explain further (AI)" : "Explain further")
      : (hasApi ? "I'm stuck — explain this (AI)" : "I'm stuck — explain this");
    return (
      <div style={{ marginTop: 8 }}>
        {!explainText && !explainLoading && !explainError && (
          <button onClick={handleExplain}
            style={{ ...S.btn("#1a1a3a", "#7ab4d4", "1px solid #2a3a5a"), width: "100%", fontSize: 12 }}>
            {btnLabel}
          </button>
        )}
        {explainLoading && (
          <div style={{ background: "#1a1a3a", borderRadius: 8, padding: 12, textAlign: "center" }}>
            <p style={{ fontSize: 12, color: "#7ab4d4", margin: 0 }}>Loading explanation...</p>
          </div>
        )}
        {explainError && (
          <div style={{ background: "#3a1a1a", borderRadius: 8, padding: 12 }}>
            <p style={{ fontSize: 12, color: "#f87171", margin: 0 }}>{explainError}</p>
            {currentProblem && (
              <div style={{ marginTop: 8 }}>
                <p style={{ fontSize: 10, color: "#7a7aaa", margin: "0 0 4px 0", ...S.mono, textTransform: "uppercase" }}>Static Explanation</p>
                <p style={{ fontSize: 13, color: "#c4c4e4", margin: 0, lineHeight: 1.7 }}>{currentProblem.explanation}</p>
              </div>
            )}
          </div>
        )}
        {explainText && (
          <div style={{ background: "#1a1a2e", border: "1px solid #2a2a4e", borderRadius: 8, padding: 14 }}>
            <p style={{ fontSize: 10, color: "#7a7aaa", margin: "0 0 6px 0", ...S.mono, textTransform: "uppercase" }}>
              {apiKey && proxyUrl ? "AI Explanation" : "Explanation"}
            </p>
            <p style={{ fontSize: 13, color: "#c4c4e4", margin: 0, lineHeight: 1.7, whiteSpace: "pre-wrap" }}>{explainText}</p>
          </div>
        )}
      </div>
    );
  };

  // ─── EXPLAIN HANDLER ──────────────────────────────────────────────────

  const handleExplain = async () => {
    if (explainLoading || explainText) return;
    if (!currentProblem) return;

    // No API configured — show static explanation
    if (!apiKey || !proxyUrl) {
      setExplainText(currentProblem.explanation);
      return;
    }

    // API configured — call it
    setExplainLoading(true);
    setExplainError("");
    try {
      const systemInstruction = [
        `You are a tutor helping an undergraduate student with ${currentProblem.topic} (${currentProblem.subject}).`,
        "Explain at an undergraduate level. Focus on WHY the answer is correct.",
        "If the student gave a wrong answer, address the specific gap between their answer and the correct answer.",
        "Keep your explanation under 200 words.",
        "Use the same terminology as the problem.",
        "Do not repeat the problem text or correct answer — the student can already see those.",
        "Be direct and clear."
      ].join(" ");

      const userMsg = [
        systemInstruction,
        "",
        `Problem: ${currentProblem.problem_text}`,
        userAnswer ? `Student's answer: ${userAnswer}` : "(Student did not provide an answer)",
        `Correct answer: ${currentProblem.answer}`,
        `Explanation: ${currentProblem.explanation}`,
        "",
        "Explain this to the student."
      ].join("\n");

      const response = await fetch(proxyUrl, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          apiKey: apiKey,
          model: "claude-sonnet-4-20250514",
          max_tokens: 1000,
          messages: [{ role: "user", content: userMsg }]
        })
      });

      if (!response.ok) throw new Error(`API returned ${response.status}`);
      const data = await response.json();
      const text = data.content
        .map(item => item.type === "text" ? item.text : "")
        .filter(Boolean)
        .join("\n");
      if (!text) throw new Error("Empty response");
      setExplainText(text);
    } catch (e) {
      setExplainError("API call failed — showing static explanation instead.");
    } finally {
      setExplainLoading(false);
    }
  };

    setExportData(JSON.stringify(data, null, 2));

    setScreen("export");

      setTimeout(() => setExportCopied(false), 2000);

    }

    if (!trimmed) {

      return;

      if (collisions.length > 0) {

        setCmErrors(collisionErrors);
        setCmPreview(null);
      } else {
        setCmPreview(result.problems);
      }
    } else {
      setCmPreview(null);
    }
  };

    await storage.save(STORAGE_KEYS.USER_CONTENT, merged);
    setCmInput("");
    setCmErrors([]);
    setCmPreview(null);
    setCmLoaded(true);
    setTimeout(() => setCmLoaded(false), 3000);
  };

    setUserContent([]);
    await storage.save(STORAGE_KEYS.USER_CONTENT, []);
    setCmDeleteConfirm(false);
  };

    const remaining = userContent.filter(p => p.topic !== topicName);

    await storage.save(STORAGE_KEYS.USER_CONTENT, remaining);
    setCmDeleteTopic(null);
  };

  if (!loaded) {
    return (
      <div style={{ minHeight: "100vh", background: "#18181b", display: "flex", alignItems: "center", justifyContent: "center" }}>
        <p style={{ color: "#a1a1aa", fontFamily: "'IBM Plex Mono', monospace", fontSize: 14 }}>Loading...</p>
      </div>
    );

  const S = {
    page: { minHeight: "100vh", background: "#18181b", color: "#e4e4e7", fontFamily: "'IBM Plex Sans', 'Segoe UI', system-ui, sans-serif", padding: "20px 16px", maxWidth: 640, margin: "0 auto" },
    mono: { fontFamily: "'IBM Plex Mono', 'Consolas', monospace" },
    accent: "#5ae4a8",
    accentDim: "#2a6a4a",
    warn: "#f59e0b",
    error: "#ef4444",
    surface: "#27272a",
    surfaceLight: "#3f3f46",
    textDim: "#a1a1aa",
    textBright: "#fafafa",
    btn: (bg, color, border) => ({
      background: bg, color, border: border || "none", borderRadius: 8,
      padding: "10px 16px", fontSize: 13, cursor: "pointer", fontFamily: "inherit"
    }),
    btnPrimary: {
      background: "#5ae4a8", color: "#18181b", border: "none", borderRadius: 10,
      padding: "14px 20px", fontSize: 15, fontWeight: 700, cursor: "pointer", fontFamily: "inherit",
      width: "100%", boxShadow: "0 2px 12px rgba(90,228,168,0.2)"
    },
  };

  if (screen === "bridge") {
    const gapDays = lastSessionTimestamp ? Math.round((now() - lastSessionTimestamp) / (24*60*60*1000)) : 0;
    return (
      <div style={S.page}>
        <div style={{ textAlign: "center", paddingTop: 60 }}>
          <p style={{ fontSize: 32, margin: "0 0 16px 0" }}>👋</p>
          <h2 style={{ fontSize: 22, fontWeight: 700, color: S.textBright, margin: "0 0 8px 0" }}>
            Welcome back
          </h2>
          <p style={{ fontSize: 14, color: S.textDim, margin: "0 0 32px 0" }}>
            It's been {gapDays} days since your last session.
          </p>
        </div>
        <div style={{ display: "flex", flexDirection: "column", gap: 10 }}>
          <button onClick={() => launchSession("full", sessionSubject, sessionTopic)} style={S.btnPrimary}>
            Pick up where I left off
          </button>

            Quick review — ease back in (8 min)

            Go to dashboard

  if (screen === "home") {

    const showGapBanner = gapHours > 24 && gapHours < 7 * 24;

    return (
      <div style={S.page}>
        <div style={{ marginBottom: 24 }}>
          <h1 style={{ fontSize: 22, fontWeight: 700, color: S.accent, margin: "0 0 4px 0", letterSpacing: "-0.02em" }}>OAT Engine</h1>
          <p style={{ fontSize: 12, color: S.textDim, margin: 0, ...S.mono }}>spaced repetition × four-phase progression × interleaving</p>
        </div>

        {/* Gap banner */}
        {showGapBanner && (

            <p style={{ fontSize: 13, color: S.warn, margin: 0 }}>

            >
              Deep study — 30 min
            </button>

            {/* Subject filter buttons — derived from loaded content */}
            {(() => {

            Topics

            Settings

        <p style={{ fontSize: 10, color: S.textDim, textAlign: "center", marginTop: 20, ...S.mono }}>
          v2.3 — {problems.length} problems • {[...new Set(problems.map(p => p.topic))].length} topics • {[...new Set(problems.map(p => p.subject))].length} subject{[...new Set(problems.map(p => p.subject))].length !== 1 ? "s" : ""}
        </p>
      </div>
    );
  }

  // ─── TOPICS SCREEN ─────────────────────────────────────────────────────

    const topicStats = getTopicStats();
    return (
      <div style={S.page}>
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 20 }}>
          <h2 style={{ fontSize: 18, fontWeight: 700, color: S.textBright, margin: 0 }}>Topic Progress</h2>
          <button onClick={() => setScreen("home")} style={S.btn("transparent", S.textDim)}>← Back</button>
        </div>
        {topicStats.map(t => {

          const topicHasWork = topicDue.due.length + topicDue.unseen.length > 0;
          return (

            <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 6 }}>

              }} />
            </div>
            {/* Study this topic button */}
            <button
              onClick={() => startSession("full", t.subject, t.topic)}
              disabled={!topicHasWork}
              style={{
                marginTop: 10, width: "100%", padding: "8px 0", fontSize: 12, fontWeight: 600,
                fontFamily: "inherit", borderRadius: 6, cursor: topicHasWork ? "pointer" : "default",
                background: topicHasWork ? "#1a2a3a" : S.surface,
                color: topicHasWork ? "#7ab4d4" : S.textDim,
                border: `1px solid ${topicHasWork ? "#2a4a5a" : S.surfaceLight}`,
                opacity: topicHasWork ? 1 : 0.5,
                ...S.mono
              }}
            >
              {topicHasWork
                ? `Study — ${topicDue.due.length} due, ${topicDue.unseen.length} new`
                : "Nothing due"}
            </button>
            {/* Practice this topic — all problems, no SRS */}
            <button
              onClick={() => launchPractice(problems.filter(prob => prob.topic === t.topic), "topics")}
              style={{
                marginTop: 6, width: "100%", padding: "8px 0", fontSize: 12, fontWeight: 600,
                fontFamily: "inherit", borderRadius: 6, cursor: "pointer",
                background: "#2a1a3a", color: "#a78bfa",
                border: "1px solid #3a2a5a", ...S.mono
              }}
            >
              Practice — {t.total} problem{t.total !== 1 ? "s" : ""}
            </button>
          </div>
          );
        })}
      </div>
    );
  }

  // ─── SEARCH SCREEN ────────────────────────────────────────────────────

  if (screen === "search") {
    const q = searchQuery.toLowerCase().trim();
    const searchModes = [
      { key: "all", label: "All" },
      { key: "problem", label: "Problem" },
      { key: "topic", label: "Topic" },
      { key: "subject", label: "Subject" }
    ];

    // Filter based on mode
    let results = [];
    if (q.length >= 2) {
      switch (searchMode) {
        case "problem":
          results = problems.filter(p => p.problem_text.toLowerCase().includes(q));
          break;
        case "topic":
          results = problems.filter(p =>
            p.topic.toLowerCase().includes(q) || p.subtopic.toLowerCase().includes(q)
          );
          break;
        case "subject":
          results = problems.filter(p => p.subject.toLowerCase().includes(q));
          break;
        default: // "all"
          results = problems.filter(p =>
            p.problem_text.toLowerCase().includes(q) ||
            p.topic.toLowerCase().includes(q) ||
            p.subtopic.toLowerCase().includes(q) ||
            p.answer.toLowerCase().includes(q) ||
            p.id.toLowerCase().includes(q)
          );
      }
    }

    // Group by topic for topic/subject modes
    const groupByTopic = (searchMode === "topic" || searchMode === "subject") && results.length > 0;
    const groupedTopics = {};
    if (groupByTopic) {
      for (const p of results) {
        if (!groupedTopics[p.topic]) {
          groupedTopics[p.topic] = { topic: p.topic, subject: p.subject, problems: [] };
        }
        groupedTopics[p.topic].problems.push(p);
      }
    }

    const phaseLabels = { 1: "Worked", 2: "Faded", 3: "Stepwise", 4: "Full" };
    const placeholders = {
      all: "Search questions, topics, answers...",
      problem: "Search by question text...",
      topic: "Search by topic or subtopic...",
      subject: "Search by subject (e.g. ochem, chem1210)..."
    };

    return (
      <div style={S.page}>
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 16 }}>
          <h2 style={{ fontSize: 18, fontWeight: 700, color: S.textBright, margin: 0 }}>Search</h2>
          <button onClick={() => setScreen("home")} style={S.btn("transparent", S.textDim)}>← Back</button>
        </div>

        {/* Mode toggles */}
        <div style={{ display: "flex", gap: 4, marginBottom: 10 }}>
          {searchModes.map(m => (
            <button key={m.key}
              onClick={() => { setSearchMode(m.key); setSearchExpanded(null); }}
              style={{
                flex: 1, padding: "6px 0", fontSize: 11, fontWeight: 600,
                fontFamily: "inherit", borderRadius: 6, cursor: "pointer",
                background: searchMode === m.key ? "#1a2a3a" : S.surface,
                color: searchMode === m.key ? "#7ab4d4" : S.textDim,
                border: `1px solid ${searchMode === m.key ? "#2a4a5a" : S.surfaceLight}`,
                ...S.mono
              }}
            >
              {m.label}
            </button>
          ))}
        </div>

        <input
          type="text"
          value={searchQuery}
          onChange={e => { setSearchQuery(e.target.value); setSearchExpanded(null); }}
          placeholder={placeholders[searchMode]}
          style={{
            width: "100%", padding: "10px 12px", fontSize: 14, borderRadius: 8,
            border: `1px solid ${S.surfaceLight}`, background: S.surface, color: S.textBright,
            fontFamily: "inherit", outline: "none", boxSizing: "border-box", marginBottom: 12
          }}
          autoFocus
        />
        {q.length > 0 && q.length < 2 && (
          <p style={{ fontSize: 12, color: S.textDim, margin: "0 0 12px 0" }}>Type at least 2 characters</p>
        )}
        {q.length >= 2 && (
          <p style={{ fontSize: 12, color: S.textDim, margin: "0 0 12px 0", ...S.mono }}>
            {groupByTopic
              ? `${Object.keys(groupedTopics).length} topic${Object.keys(groupedTopics).length !== 1 ? "s" : ""} · ${results.length} problem${results.length !== 1 ? "s" : ""}`
              : `${results.length} result${results.length !== 1 ? "s" : ""}`}
          </p>
        )}

        {/* Practice all results button */}
        {results.length > 1 && (
          <button
            onClick={() => launchPractice(results, "search")}
            style={{
              width: "100%", padding: "10px 0", fontSize: 13, fontWeight: 600,
              fontFamily: "inherit", borderRadius: 8, cursor: "pointer", marginBottom: 12,
              background: "#2a1a3a", color: "#a78bfa",
              border: "1px solid #3a2a5a", ...S.mono
            }}
          >
            Practice all {results.length} results
          </button>
        )}

        {/* Grouped view for topic/subject modes */}
        {groupByTopic && (
          <div style={{ display: "flex", flexDirection: "column", gap: 8 }}>
            {Object.values(groupedTopics).map(g => (
              <div key={g.topic} style={{ background: S.surface, borderRadius: 10, padding: 14 }}>
                <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 6 }}>
                  <span style={{ fontSize: 14, fontWeight: 600, color: S.textBright }}>{g.topic}</span>
                  <span style={{ fontSize: 11, color: S.textDim, ...S.mono }}>{g.subject}</span>
                </div>
                <p style={{ fontSize: 12, color: S.textDim, margin: "0 0 10px 0", ...S.mono }}>
                  {g.problems.length} problem{g.problems.length !== 1 ? "s" : ""}
                </p>
                <button
                  onClick={() => launchPractice(g.problems, "search")}
                  style={{
                    width: "100%", padding: "8px 0", fontSize: 12, fontWeight: 600,
                    fontFamily: "inherit", borderRadius: 6, cursor: "pointer",
                    background: "#2a1a3a", color: "#a78bfa",
                    border: "1px solid #3a2a5a", ...S.mono
                  }}
                >
                  Practice — {g.problems.length} problem{g.problems.length !== 1 ? "s" : ""}
                </button>
              </div>
            ))}
          </div>
        )}

        {/* Individual results for all/problem modes */}
        {!groupByTopic && (
          <div style={{ display: "flex", flexDirection: "column", gap: 8 }}>
            {results.slice(0, 50).map(p => {
              const isOpen = searchExpanded === p.id;
              const prog = progress[p.id];
              return (
                <div key={p.id}
                  onClick={() => setSearchExpanded(isOpen ? null : p.id)}
                  style={{
                    background: S.surface, borderRadius: 10, padding: 14, cursor: "pointer",
                    border: `1px solid ${isOpen ? S.accent : "transparent"}`
                  }}
                >
                  {/* Collapsed: summary line */}
                  <div style={{ display: "flex", justifyContent: "space-between", alignItems: "flex-start", gap: 8 }}>
                    <p style={{ fontSize: 13, color: S.textBright, margin: 0, flex: 1 }}>
                      {p.problem_text.length > 120 ? p.problem_text.slice(0, 120) + "…" : p.problem_text}
                    </p>
                    <span style={{ fontSize: 10, color: S.textDim, ...S.mono, whiteSpace: "nowrap" }}>
                      P{p.phase}
                    </span>
                  </div>
                  <div style={{ display: "flex", gap: 8, marginTop: 6, fontSize: 11, color: S.textDim, ...S.mono, flexWrap: "wrap" }}>
                    <span>{p.topic}</span>
                    <span>·</span>
                    <span>{phaseLabels[p.phase] || `P${p.phase}`}</span>
                    <span>·</span>
                    <span>D{p.difficulty}</span>
                    {prog && <><span>·</span><span>{prog.attempts} attempt{prog.attempts !== 1 ? "s" : ""}</span></>}
                  </div>

                  {/* Expanded: full details */}
                  {isOpen && (
                    <div style={{ marginTop: 12, paddingTop: 12, borderTop: `1px solid ${S.surfaceLight}` }}>
                      <p style={{ fontSize: 12, color: S.textDim, margin: "0 0 4px 0", ...S.mono, textTransform: "uppercase" }}>
                        {p.subtopic} — {p.subject}
                      </p>
                      <p style={{ fontSize: 13, color: S.textBright, margin: "8px 0", whiteSpace: "pre-wrap" }}>
                        {p.problem_text}
                      </p>
                      {p.steps && p.steps.length > 0 && (
                        <div style={{ margin: "8px 0" }}>
                          <p style={{ fontSize: 11, color: S.textDim, ...S.mono, margin: "0 0 6px 0", textTransform: "uppercase" }}>Steps</p>
                          {p.steps.map((s, i) => (
                            <div key={i} style={{ fontSize: 12, color: s.hidden ? "#7ab4d4" : S.textDim, margin: "4px 0", paddingLeft: 8, borderLeft: `2px solid ${s.hidden ? "#2a4a5a" : S.surfaceLight}` }}>
                              {s.text}
                            </div>
                          ))}
                        </div>
                      )}
                      <div style={{ marginTop: 10, padding: 10, background: "#1a2a1a", borderRadius: 6, border: "1px solid #2a4a2a" }}>
                        <p style={{ fontSize: 11, color: S.textDim, ...S.mono, margin: "0 0 4px 0", textTransform: "uppercase" }}>Answer</p>
                        <p style={{ fontSize: 13, color: S.accent, margin: 0 }}>{p.answer}</p>
                      </div>
                      {p.explanation && (
                        <div style={{ marginTop: 8, fontSize: 12, color: S.textDim }}>
                          <p style={{ ...S.mono, fontSize: 11, margin: "0 0 4px 0", textTransform: "uppercase" }}>Explanation</p>
                          <p style={{ margin: 0, whiteSpace: "pre-wrap" }}>{p.explanation}</p>
                        </div>
                      )}
                      {prog && (
                        <div style={{ marginTop: 10, fontSize: 11, color: S.textDim, ...S.mono, display: "flex", gap: 10, flexWrap: "wrap" }}>
                          <span>{prog.attempts} attempts</span>
                          <span>{Math.round((prog.accuracy || 0) * 100)}% accuracy</span>
                          <span>next due: {prog.nextDue <= now() ? "now" : new Date(prog.nextDue).toLocaleDateString()}</span>
                        </div>
                      )}
                      <button
                        onClick={(e) => { e.stopPropagation(); launchPractice([p], "search"); }}
                        style={{
                          marginTop: 12, width: "100%", padding: "8px 0", fontSize: 12, fontWeight: 600,
                          fontFamily: "inherit", borderRadius: 6, cursor: "pointer",
                          background: "#2a1a3a", color: "#a78bfa",
                          border: "1px solid #3a2a5a", ...S.mono
                        }}
                      >
                        Practice this problem
                      </button>
                    </div>
                  )}
                </div>
              );
            })}
            {results.length > 50 && (
              <p style={{ fontSize: 12, color: S.textDim, textAlign: "center", ...S.mono }}>
                Showing first 50 of {results.length} results — narrow your search
              </p>
            )}
          </div>
        )}
      </div>
    );
  }

  // ─── HISTORY SCREEN ──────────────────────────────────────────────────

  if (screen === "history") {
    const sortedLog = [...sessionLog].reverse();
    const totalSessions = sortedLog.length;
    const totalProblems = sortedLog.reduce((sum, s) => sum + s.total, 0);
    const totalCorrect = sortedLog.reduce((sum, s) => sum + s.correct, 0);
    const overallAccuracy = totalProblems > 0 ? Math.round((totalCorrect / totalProblems) * 100) : null;
    const totalTime = sortedLog.reduce((sum, s) => sum + s.elapsed, 0);

    return (
      <div style={S.page}>
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 20 }}>
          <h2 style={{ fontSize: 18, fontWeight: 700, color: S.textBright, margin: 0 }}>Session History</h2>
          <button onClick={() => setScreen("home")} style={S.btn("transparent", S.textDim)}>← Back</button>
        </div>

        {totalSessions === 0 ? (
          <p style={{ fontSize: 14, color: S.textDim, textAlign: "center", marginTop: 40 }}>No sessions yet. Go study!</p>
        ) : (
          <>
            {/* Summary */}
            <div style={{ display: "grid", gridTemplateColumns: "1fr 1fr 1fr", gap: 8, marginBottom: 20 }}>
              {[
                { label: "Sessions", value: totalSessions },
                { label: "Problems", value: totalProblems },
                { label: "Accuracy", value: overallAccuracy !== null ? `${overallAccuracy}%` : "—" }
              ].map(s => (
                <div key={s.label} style={{ background: S.surface, borderRadius: 10, padding: "12px 10px", textAlign: "center" }}>
                  <p style={{ fontSize: 20, fontWeight: 700, margin: 0, color: S.textBright }}>{s.value}</p>
                  <p style={{ fontSize: 10, color: S.textDim, margin: "2px 0 0 0", ...S.mono, textTransform: "uppercase" }}>{s.label}</p>
                </div>
              ))}
            </div>
            <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 16px 0", ...S.mono }}>
              Total study time: {Math.floor(totalTime / 3600)}h {Math.floor((totalTime % 3600) / 60)}m
            </p>

            {/* Session list */}
            <div style={{ display: "flex", flexDirection: "column", gap: 6 }}>
              {sortedLog.map((s, i) => {
                const pct = s.total > 0 ? Math.round((s.correct / s.total) * 100) : 0;
                const mins = Math.floor(s.elapsed / 60);
                const secs = s.elapsed % 60;
                const dateStr = new Date(s.timestamp).toLocaleDateString(undefined, { month: "short", day: "numeric" });
                const timeStr = new Date(s.timestamp).toLocaleTimeString(undefined, { hour: "numeric", minute: "2-digit" });
                return (
                  <div key={i} style={{ background: S.surface, borderRadius: 8, padding: "10px 14px", display: "flex", justifyContent: "space-between", alignItems: "center" }}>
                    <div>
                      <p style={{ fontSize: 13, color: S.textBright, margin: 0, fontWeight: 500 }}>
                        {dateStr} · {timeStr}
                      </p>
                      <p style={{ fontSize: 11, color: S.textDim, margin: "2px 0 0 0", ...S.mono }}>
                        {s.correct}/{s.total} · {mins}:{secs.toString().padStart(2, "0")}
                      </p>
                    </div>
                    <span style={{
                      ...S.mono, fontSize: 14, fontWeight: 700,
                      color: pct >= 85 ? S.accent : pct >= 70 ? S.warn : S.error
                    }}>
                      {pct}%
                    </span>
                  </div>
                );
              })}
            </div>
          </>
        )}
      </div>
    );
  }

  // ─── STUDY SCREEN ──────────────────────────────────────────────────────

  if (screen === "study" && currentProblem) {
    const p = currentProblem;
    const phaseLabels = { 1: "Worked Example", 2: "Complete the Solution", 3: "Step by Step", 4: "Solve It" };
    const phaseBg = { 1: "#1e3a5f", 2: "#1e3a4f", 3: "#2a1e4f", 4: "#3a1e2f" };
    const rollingPct = getRollingAccuracyPct();

    const visibleSteps = p.steps.filter(s => !s.hidden);
    const hiddenSteps = p.steps.filter(s => s.hidden);
    const totalHidden = hiddenSteps.length;

    return (
      <div style={S.page}>
        {/* Top bar */}
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 16 }}>
          <div style={{ display: "flex", alignItems: "center", gap: 10 }}>
            {practiceMode ? (
              <span style={{ ...S.mono, fontSize: 16, fontWeight: 700, color: "#a78bfa" }}>
                Practice — {practiceIndex + 1}/{practiceQueue.length}
              </span>
            ) : (
              <>
                <span style={{
                  ...S.mono, fontSize: 20, fontWeight: 700,
                  color: timerExpired ? S.textDim : sessionTimer < 120 ? S.warn : S.accent
                }}>
                  {timerExpired ? "Finish up" : formatTime(sessionTimer)}
                </span>
                {rollingPct !== null && (
                  <span style={{ ...S.mono, fontSize: 12, color: rollingPct >= 85 ? S.accent : rollingPct >= 70 ? S.warn : S.error }}>
                    {rollingPct}%
                  </span>
                )}
              </>
            )}
          </div>
          <div style={{ display: "flex", alignItems: "center", gap: 10 }}>
            {!practiceMode && <span style={{ ...S.mono, fontSize: 12, color: S.textDim }}>#{sessionProblems.length + 1}</span>}
            <button onClick={skipProblem} style={S.btn("none", S.textDim, `1px solid ${S.surfaceLight}`)}>
              Skip
            </button>
            <button onClick={endSession} style={S.btn("none", S.textDim, `1px solid ${S.surfaceLight}`)}>
              {practiceMode ? "Exit" : "End"}
            </button>
          </div>
        </div>

        {/* Timer expired banner — soft end, don't force */}
        {!practiceMode && timerExpired && (
          <div style={{ background: "#1a2a2a", border: `1px solid #2a4a4a`, borderRadius: 8, padding: 10, marginBottom: 12 }}>
            <p style={{ fontSize: 12, color: S.textDim, margin: 0 }}>
              Good session. Finish this problem — no rush — then we'll wrap up.
            </p>
          </div>
        )}

        {/* Phase badge + subject */}
        <div style={{ display: "flex", gap: 8, marginBottom: 12, alignItems: "center" }}>
          <div style={{
            padding: "3px 8px", borderRadius: 5, background: phaseBg[p.phase],
            color: S.textDim, fontSize: 10, ...S.mono, textTransform: "uppercase", letterSpacing: "0.05em"
          }}>
            P{p.phase} — {phaseLabels[p.phase]}
          </div>
          <div style={{
            padding: "3px 8px", borderRadius: 5, background: "#1a1a2a",
            color: "#7a7aaa", fontSize: 10, ...S.mono
          }}>
            {p.subtopic}
          </div>
        </div>

        {/* Difficulty dots */}
        <div style={{ display: "flex", gap: 3, marginBottom: 14 }}>
          {[1,2,3,4,5].map(d => (
            <div key={d} style={{
              width: 5, height: 5, borderRadius: "50%",
              background: d <= p.difficulty ? S.accent : S.surfaceLight
            }} />
          ))}
        </div>

        {/* Problem text */}
        <div style={{ background: S.surface, borderRadius: 10, padding: 16, marginBottom: 14 }}>
          <p style={{ fontSize: 15, lineHeight: 1.6, margin: 0, color: S.textBright, fontWeight: 500 }}>
            {p.problem_text}
          </p>
        </div>

        {/* ── Phase 1: Worked Example ── */}
        {p.phase === 1 && (
          <div>
            {p.steps.map((step, i) => (
              <div key={i} style={{
                background: "#1a2a1a", borderLeft: `3px solid ${S.accentDim}`,
                padding: "10px 14px", marginBottom: 6, borderRadius: "0 8px 8px 0"
              }}>
                <p style={{ fontSize: 13, margin: 0, color: "#c4d4c4", lineHeight: 1.6 }}>
                  <span style={{ color: S.accent, ...S.mono, fontSize: 10, marginRight: 8 }}>Step {i + 1}</span>
                  {step.text}
                </p>
              </div>
            ))}
            {p.self_explanation && !showSelfExplanation && (
              <button onClick={() => setShowSelfExplanation(true)}
                style={{ width: "100%", background: "#2a2a1a", border: `1px solid #4a4a2a`, borderRadius: 8, padding: 14, marginTop: 10, cursor: "pointer", textAlign: "left", fontFamily: "inherit" }}>
                <p style={{ fontSize: 13, margin: 0, color: S.warn }}>💡 Self-check: {p.self_explanation}</p>
                <p style={{ fontSize: 11, margin: "4px 0 0 0", color: S.textDim }}>Tap to think, then reveal</p>
              </button>
            )}
            {showSelfExplanation && (
              <div style={{ background: "#2a2a1a", border: `1px solid #4a4a2a`, borderRadius: 8, padding: 14, marginTop: 10 }}>
                <p style={{ fontSize: 13, margin: 0, color: S.warn }}>💡 {p.self_explanation}</p>
                {!selfExplanationRevealed ? (
                  <button onClick={() => setSelfExplanationRevealed(true)}
                    style={{ ...S.btn(S.surfaceLight, S.textDim), marginTop: 8, fontSize: 12 }}>
                    Reveal explanation
                  </button>
                ) : (
                  <p style={{ fontSize: 13, margin: "8px 0 0 0", color: "#d4d4a4", lineHeight: 1.6 }}>{p.self_explanation_answer}</p>
                )}
              </div>
            )}
            {renderExplainButton(true)}
            {!showAnswer && (
              <button onClick={() => recordStudied()}
                style={{ ...S.btnPrimary, marginTop: 14, fontSize: 14 }}>
                I've studied this — Next
              </button>
            )}
            {showAnswer && (
              <button onClick={nextProblem}
                style={{ ...S.btn(S.surface, S.accent, `1px solid ${S.accentDim}`), width: "100%", marginTop: 14, fontWeight: 600, fontSize: 14 }}>
                Continue →
              </button>
            )}
          </div>
        )}

        {/* ── Phase 2: Faded Completion ── */}
        {p.phase === 2 && (
          <div>
            {visibleSteps.map((step, i) => (
              <div key={i} style={{
                background: "#1a2a1a", borderLeft: `3px solid ${S.accentDim}`,
                padding: "10px 14px", marginBottom: 6, borderRadius: "0 8px 8px 0"
              }}>
                <p style={{ fontSize: 13, margin: 0, color: "#c4d4c4", lineHeight: 1.6 }}>
                  <span style={{ color: S.accent, ...S.mono, fontSize: 10, marginRight: 8 }}>Step {i + 1}</span>
                  {step.text}
                </p>
              </div>
            ))}
            {!showAnswer && hiddenSteps.map((step, i) => (
              <div key={`h-${i}`} style={{
                background: "#2a1a2a", borderLeft: `3px solid #6a3a6a`,
                padding: "10px 14px", marginBottom: 6, borderRadius: "0 8px 8px 0"
              }}>
                {revealedSteps > i ? (
                  <p style={{ fontSize: 13, margin: 0, color: "#d4b4d4", lineHeight: 1.6 }}>
                    <span style={{ ...S.mono, fontSize: 10, marginRight: 8, color: "#a47aa4" }}>Your turn</span>
                    {step.reveal_text || step.text}
                  </p>
                ) : (
                  <p style={{ fontSize: 13, margin: 0, color: "#8a6a8a" }}>
                    <span style={{ ...S.mono, fontSize: 10, marginRight: 8 }}>?</span>
                    Complete this step...
                  </p>
                )}
              </div>
            ))}
            {!showAnswer && revealedSteps < totalHidden && (
              <button onClick={() => setRevealedSteps(prev => prev + 1)}
                style={{ ...S.btn("#3a2a3a", "#d4b4d4", "1px solid #5a3a5a"), width: "100%", marginTop: 6 }}>
                Reveal next step ({revealedSteps + 1}/{totalHidden})
              </button>
            )}
            {!showAnswer && revealedSteps >= totalHidden && (
              <div style={{ display: "flex", gap: 8, marginTop: 10 }}>
                <button onClick={() => recordAnswer(true)}
                  style={{ ...S.btn("#1a3a2a", S.accent, `1px solid ${S.accentDim}`), flex: 1 }}>I got it right ✓</button>
                <button onClick={() => recordAnswer(false)}
                  style={{ ...S.btn("#3a1a1a", "#f87171", "1px solid #5a2a2a"), flex: 1 }}>I got it wrong ✗</button>
              </div>
            )}
            {showAnswer && (
              <div style={{ marginTop: 10 }}>
                <div style={{ background: S.surface, borderRadius: 8, padding: 14, marginBottom: 8 }}>
                  <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 4px 0", ...S.mono, textTransform: "uppercase" }}>Full answer</p>
                  <p style={{ fontSize: 14, color: S.textBright, margin: 0, lineHeight: 1.5 }}>{p.answer}</p>
                </div>
                {renderExplainButton()}
                <button onClick={nextProblem}
                  style={{ ...S.btn(S.surface, S.accent, `1px solid ${S.accentDim}`), width: "100%", fontWeight: 600, fontSize: 14, marginTop: 8 }}>
                  Continue →
                </button>
              </div>
            )}
          </div>
        )}

        {/* ── Phase 3: Stepwise Retrieval ── */}
        {p.phase === 3 && (
          <div>
            {p.steps.map((step, i) => (
              <div key={i} style={{ marginBottom: 6 }}>
                {i < revealedSteps ? (
                  <div style={{ background: "#1a1a2a", borderLeft: "3px solid #4a4aaa", padding: "10px 14px", borderRadius: "0 8px 8px 0" }}>
                    <p style={{ fontSize: 13, margin: 0, color: "#b4b4d4", lineHeight: 1.6 }}>
                      <span style={{ ...S.mono, fontSize: 10, marginRight: 8, color: "#7a7aaa" }}>Step {i + 1}</span>
                      {step.reveal_text || step.text}
                    </p>
                  </div>
                ) : i === revealedSteps ? (
                  <div style={{ background: "#2a1a3a", borderLeft: "3px solid #8a5aaa", padding: "10px 14px", borderRadius: "0 8px 8px 0" }}>
                    <p style={{ fontSize: 13, margin: 0, color: "#d4b4e4", fontWeight: 500 }}>
                      {step.text.replace(/\?$/, "").trim()}?
                    </p>
                  </div>
                ) : (
                  <div style={{ background: "#1a1a1e", borderLeft: "3px solid #3a3a3e", padding: "10px 14px", borderRadius: "0 8px 8px 0", opacity: 0.4 }}>
                    <p style={{ fontSize: 13, margin: 0, color: S.textDim }}>
                      <span style={{ ...S.mono, fontSize: 10 }}>Step {i + 1}</span> — locked
                    </p>
                  </div>
                )}
              </div>
            ))}
            {!showAnswer && revealedSteps < p.steps.length && (
              <button onClick={() => setRevealedSteps(prev => prev + 1)}
                style={{ ...S.btn("#2a1a3a", "#d4b4e4", "1px solid #5a3a6a"), width: "100%", marginTop: 6 }}>
                I've thought about it — reveal ({revealedSteps + 1}/{p.steps.length})
              </button>
            )}
            {!showAnswer && revealedSteps >= p.steps.length && (
              <div style={{ display: "flex", gap: 8, marginTop: 10 }}>
                <button onClick={() => recordAnswer(true)}
                  style={{ ...S.btn("#1a3a2a", S.accent, `1px solid ${S.accentDim}`), flex: 1 }}>I predicted correctly ✓</button>
                <button onClick={() => recordAnswer(false)}
                  style={{ ...S.btn("#3a1a1a", "#f87171", "1px solid #5a2a2a"), flex: 1 }}>I got it wrong ✗</button>
              </div>
            )}
            {showAnswer && (
              <div style={{ marginTop: 10 }}>
                <div style={{ background: S.surface, borderRadius: 8, padding: 14, marginBottom: 8 }}>
                  <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 4px 0", ...S.mono, textTransform: "uppercase" }}>Full answer</p>
                  <p style={{ fontSize: 14, color: S.textBright, margin: 0, lineHeight: 1.5 }}>{p.answer}</p>
                  <p style={{ fontSize: 13, color: S.textDim, margin: "6px 0 0 0", lineHeight: 1.5 }}>{p.explanation}</p>
                </div>
                {renderExplainButton()}
                <button onClick={nextProblem}
                  style={{ ...S.btn(S.surface, S.accent, `1px solid ${S.accentDim}`), width: "100%", fontWeight: 600, fontSize: 14, marginTop: 8 }}>
                  Continue →
                </button>
              </div>
            )}
          </div>
        )}

        {/* ── Phase 4: Full Problem ── */}
        {p.phase === 4 && (
          <div>
            {!showAnswer ? (
              <div>
                <textarea value={userAnswer} onChange={e => setUserAnswer(e.target.value)}
                  placeholder="Type your answer: mechanism + product..."
                  style={{
                    width: "100%", minHeight: 80, background: S.surface, color: S.textBright,
                    border: `1px solid ${S.surfaceLight}`, borderRadius: 8, padding: 14,
                    fontSize: 14, fontFamily: "inherit", resize: "vertical", lineHeight: 1.5, boxSizing: "border-box"
                  }}
                />
                <div style={{ display: "flex", gap: 8, marginTop: 10 }}>
                  <button onClick={() => setShowAnswer(true)}
                    style={{ ...S.btn(S.surfaceLight, S.textDim), flex: 1 }}>Show answer</button>
                </div>
              </div>
            ) : (
              <div>
                {userAnswer && (
                  <div style={{ background: "#1a1a2a", borderRadius: 8, padding: 14, marginBottom: 8 }}>
                    <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 4px 0", ...S.mono, textTransform: "uppercase" }}>Your answer</p>
                    <p style={{ fontSize: 14, color: "#b4b4d4", margin: 0, lineHeight: 1.5 }}>{userAnswer}</p>
                  </div>
                )}
                <div style={{ background: "#1a2a1a", borderRadius: 8, padding: 14, marginBottom: 8 }}>
                  <p style={{ fontSize: 11, color: S.accent, margin: "0 0 4px 0", ...S.mono, textTransform: "uppercase" }}>Correct answer</p>
                  <p style={{ fontSize: 14, color: S.textBright, margin: 0, lineHeight: 1.5, fontWeight: 500 }}>{p.answer}</p>
                  <p style={{ fontSize: 13, color: "#a4c4a4", margin: "8px 0 0 0", lineHeight: 1.6 }}>{p.explanation}</p>
                </div>
                {renderExplainButton()}
                {!problemGraded ? (
                  <div style={{ display: "flex", gap: 8 }}>
                    <button onClick={() => recordAnswer(true)}
                      style={{ ...S.btn("#1a3a2a", S.accent, `1px solid ${S.accentDim}`), flex: 1 }}>I got it right ✓</button>
                    <button onClick={() => recordAnswer(false)}
                      style={{ ...S.btn("#3a1a1a", "#f87171", "1px solid #5a2a2a"), flex: 1 }}>I got it wrong ✗</button>
                  </div>
                ) : (
                  <button onClick={nextProblem}
                    style={{ ...S.btn(S.surface, S.accent, `1px solid ${S.accentDim}`), width: "100%", fontWeight: 600, fontSize: 14 }}>
                    Continue →
                  </button>
                )}
              </div>
            )}
          </div>
        )}

        {/* Consecutive error warning — shown after grading, not during */}
        {consecutiveErrors >= 2 && showAnswer && (
          <div style={{ background: "#2a2a1a", border: `1px solid #3a3a2a`, borderRadius: 8, padding: 10, marginTop: 10 }}>
            <p style={{ fontSize: 12, color: S.textDim, margin: 0 }}>
              {consecutiveErrors} in a row — no sweat. Next one will be easier.
            </p>
          </div>
        )}
      </div>
    );
  }

  // ─── SUMMARY SCREEN ────────────────────────────────────────────────────

  if (screen === "summary") {
    const total = sessionProblems.length;
    const correct = sessionProblems.filter(p => p.correct).length;
    const pct = total > 0 ? Math.round((correct / total) * 100) : 0;
    const elapsed = sessionStartTime ? Math.round((now() - sessionStartTime) / 1000) : 0;
    const topicsCovered = [...new Set(sessionProblems.map(sp => sp.topic))].length;

    return (
      <div style={S.page}>
        <div style={{ textAlign: "center", paddingTop: 32 }}>
          <p style={{ fontSize: 36, margin: "0 0 8px 0" }}>
            {pct >= 85 ? "🟢" : pct >= 70 ? "🟡" : "🔴"}
          </p>
          <h2 style={{ fontSize: 26, fontWeight: 700, color: S.textBright, margin: "0 0 4px 0" }}>
            {correct}/{total} correct
          </h2>
          <p style={{ fontSize: 13, color: S.textDim, margin: 0 }}>
            {pct}% accuracy • {formatTime(elapsed)} • {topicsCovered} topic{topicsCovered !== 1 ? "s" : ""}
          </p>
        </div>

        <div style={{ background: S.surface, borderRadius: 12, padding: 14, marginTop: 24 }}>
          <p style={{ fontSize: 11, color: S.textDim, ...S.mono, textTransform: "uppercase", letterSpacing: "0.05em", margin: "0 0 10px 0" }}>This session</p>
          {sessionProblems.map((sp, i) => {
            const prob = problems.find(p => p.id === sp.id);
            return (
              <div key={i} style={{ display: "flex", justifyContent: "space-between", alignItems: "center", padding: "5px 0", borderBottom: i < sessionProblems.length - 1 ? `1px solid ${S.surfaceLight}` : "none" }}>
                <span style={{ fontSize: 12, color: S.textDim, flex: 1, overflow: "hidden", textOverflow: "ellipsis", whiteSpace: "nowrap", marginRight: 8 }}>
                  {prob?.subtopic || "Problem"}
                </span>
                <span style={{ fontSize: 12, ...S.mono, color: sp.correct ? S.accent : S.error }}>
                  {sp.correct ? "✓" : "✗"}
                </span>
              </div>
            );
          })}
        </div>

        {pct >= 85 && (
          <p style={{ textAlign: "center", fontSize: 13, color: S.accent, marginTop: 16 }}>
            Strong session. Spaced repetition will bring these back at the right time.
          </p>
        )}
        {pct >= 70 && pct < 85 && (
          <p style={{ textAlign: "center", fontSize: 13, color: S.warn, marginTop: 16 }}>
            Solid work. Missed items will come back sooner for review.
          </p>
        )}
        {pct < 70 && (
          <p style={{ textAlign: "center", fontSize: 13, color: "#f87171", marginTop: 16 }}>
            Tough round — that's the learning happening. Missed items scheduled for quicker review.
          </p>
        )}

        {sessionLog.length > 0 && sessionLog.length % 10 === 0 && (
          <div style={{ background: "#1a2a3a", border: "1px solid #2a4a5a", borderRadius: 8, padding: 12, marginTop: 16 }}>
            <p style={{ fontSize: 12, color: "#7ab4d4", margin: 0 }}>
              📦 You've completed {sessionLog.length} sessions — good time to export a backup from the home screen.
            </p>
          </div>
        )}

        <button onClick={() => setScreen("home")} style={{ ...S.btnPrimary, marginTop: 20 }}>
          Done
        </button>
      </div>
    );
  }

  // ─── CONTENT MANAGER SCREEN ──────────────────────────────────────────

  if (screen === "content") {
    const allSummary = getContentSummary(problems);

    return (
      <div style={S.page}>
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 20 }}>
          <h2 style={{ fontSize: 18, fontWeight: 700, color: S.textBright, margin: 0 }}>Content Manager</h2>
          <button onClick={() => setScreen("home")} style={S.btn("transparent", S.textDim)}>← Back</button>
        </div>

        {/* Tabs */}
        <div style={{ display: "flex", gap: 4, marginBottom: 16 }}>
          {[["paste", "Add Content"], ["inventory", "Inventory"]].map(([key, label]) => (
            <button key={key} onClick={() => setCmTab(key)}
              style={{
                flex: 1, padding: "8px 12px", fontSize: 12, borderRadius: 6, cursor: "pointer",
                fontFamily: "inherit", border: "1px solid",
                background: cmTab === key ? "#1a2a3a" : S.surface,
                color: cmTab === key ? "#7ab4d4" : S.textDim,
                borderColor: cmTab === key ? "#2a4a5a" : S.surfaceLight
              }}>
              {label}
            </button>
          ))}
        </div>

        {/* ── PASTE TAB ── */}
        {cmTab === "paste" && (
          <div>
            {/* Reference guide */}
            <div style={{ background: "#1a1a2e", border: "1px solid #2a2a4e", borderRadius: 8, padding: 14, marginBottom: 14 }}>
              <p style={{ fontSize: 12, fontWeight: 600, color: "#7ab4d4", margin: "0 0 8px 0" }}>Quick Reference</p>
              <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 6px 0", lineHeight: 1.6 }}>
                <span style={{ color: "#7ab4d4" }}>Phases:</span> 1 = Worked Example (all steps shown), 2 = Faded Completion (some hidden), 3 = Stepwise Retrieval (all hidden), 4 = Full Problem (no steps)
              </p>
              <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 6px 0", lineHeight: 1.6 }}>
                <span style={{ color: "#7ab4d4" }}>Difficulty:</span> 1 = easiest → 5 = hardest. Affects scheduling order.
              </p>
              <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 6px 0", lineHeight: 1.6 }}>
                <span style={{ color: "#7ab4d4" }}>conceptId:</span> Problems with the same conceptId are linked — the app won't show Phase 3 "sn2" until you pass Phase 2 "sn2." Use the same conceptId for all problems about the same concept across phases.
              </p>
              <p style={{ fontSize: 11, color: S.textDim, margin: 0, lineHeight: 1.6 }}>
                <span style={{ color: "#7ab4d4" }}>subject:</span> Any short label — "ochem", "trig", "anatomy", etc. Used for filtering on the home screen.
              </p>
            </div>

            {/* Paste area */}
            <textarea
              value={cmInput}
              onChange={e => { setCmInput(e.target.value); setCmErrors([]); setCmPreview(null); }}
              placeholder={'Paste your JSON problem array here...\n\nExample: [\n  {\n    "id": "my-problem-1",\n    "subject": "trig",\n    "topic": "Unit Circle",\n    ...\n  }\n]'}
              style={{
                width: "100%", minHeight: 140, background: S.surface, color: S.textBright,
                border: `1px solid ${S.surfaceLight}`, borderRadius: 8, padding: 14,
                fontSize: 12, fontFamily: "'IBM Plex Mono', monospace", resize: "vertical",
                lineHeight: 1.5, boxSizing: "border-box"
              }}
            />

            <button onClick={handleCmValidate}
              style={{ ...S.btn("#1a2a3a", "#7ab4d4", "1px solid #2a4a5a"), width: "100%", marginTop: 8, fontSize: 13, fontWeight: 600 }}>
              Validate
            </button>

            {/* Errors */}
            {cmErrors.length > 0 && (
              <div style={{ background: "#3a1a1a", border: "1px solid #5a2a2a", borderRadius: 8, padding: 12, marginTop: 12, maxHeight: 200, overflow: "auto" }}>
                <p style={{ fontSize: 11, color: "#f87171", margin: "0 0 8px 0", fontWeight: 600 }}>{cmErrors.length} issue{cmErrors.length !== 1 ? "s" : ""} found:</p>
                {cmErrors.map((err, i) => (
                  <p key={i} style={{ fontSize: 11, color: "#d4a4a4", margin: "0 0 4px 0", lineHeight: 1.5, paddingLeft: 8, borderLeft: "2px solid #5a2a2a" }}>
                    {err}
                  </p>
                ))}
              </div>
            )}

            {/* Preview */}
            {cmPreview && (
              <div style={{ background: "#1a2a1a", border: "1px solid #2a4a2a", borderRadius: 8, padding: 12, marginTop: 12 }}>
                <p style={{ fontSize: 12, color: S.accent, margin: "0 0 8px 0", fontWeight: 600 }}>
                  ✓ Valid — {cmPreview.length} problem{cmPreview.length !== 1 ? "s" : ""} ready to load
                </p>
                {getContentSummary(cmPreview).map(s => (
                  <div key={s.topic} style={{ display: "flex", justifyContent: "space-between", fontSize: 11, color: "#a4c4a4", padding: "3px 0" }}>
                    <span>{s.topic}</span>
                    <span style={{ ...S.mono }}>
                      {Object.entries(s.phases).filter(([_, c]) => c > 0).map(([ph, c]) => `P${ph}:${c}`).join(" ")}
                    </span>
                  </div>
                ))}
                <button onClick={handleCmLoad}
                  style={{ ...S.btnPrimary, marginTop: 12, fontSize: 13 }}>
                  Load {cmPreview.length} problem{cmPreview.length !== 1 ? "s" : ""} into the app
                </button>
              </div>
            )}

            {/* Load success */}
            {cmLoaded && (
              <div style={{ background: "#1a3a2a", border: `1px solid ${S.accentDim}`, borderRadius: 8, padding: 10, marginTop: 10 }}>
                <p style={{ fontSize: 12, color: S.accent, margin: 0 }}>✓ Content loaded. You can study it now.</p>
              </div>
            )}
          </div>
        )}

        {/* ── INVENTORY TAB ── */}
        {cmTab === "inventory" && (
          <div>
            <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 12px 0", ...S.mono, textTransform: "uppercase", letterSpacing: "0.05em" }}>
              All content — {problems.length} problem{problems.length !== 1 ? "s" : ""} • {[...new Set(problems.map(p => p.subject))].length} subject{[...new Set(problems.map(p => p.subject))].length !== 1 ? "s" : ""}
            </p>

            {allSummary.map(s => (
              <div key={s.topic} style={{ background: S.surface, borderRadius: 8, padding: 12, marginBottom: 6 }}>
                <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center" }}>
                  <span style={{ fontSize: 13, fontWeight: 600, color: S.textBright }}>{s.topic}</span>
                  <span style={{ fontSize: 10, color: S.textDim, ...S.mono }}>{s.subject} • {s.total}</span>
                </div>
                <div style={{ display: "flex", gap: 8, marginTop: 6 }}>
                  {[1,2,3,4].map(ph => (
                    <div key={ph} style={{
                      flex: 1, textAlign: "center", padding: "4px 0", borderRadius: 4,
                      background: s.phases[ph] > 0 ? "#1a2a1a" : "#1a1a1e",
                    }}>
                      <span style={{ fontSize: 10, color: s.phases[ph] > 0 ? S.accent : S.textDim, ...S.mono }}>
                        P{ph}: {s.phases[ph] || 0}
                      </span>
                    </div>
                  ))}
                </div>
                {cmDeleteTopic === s.topic ? (
                  <div style={{ display: "flex", gap: 6, marginTop: 8 }}>
                    <button onClick={() => handleCmDeleteTopic(s.topic)}
                      style={{ ...S.btn("#5a1a1a", "#f87171", "1px solid #7a2a2a"), flex: 1, fontSize: 11 }}>
                      Delete {s.total} problem{s.total !== 1 ? "s" : ""}
                    </button>
                    <button onClick={() => setCmDeleteTopic(null)}
                      style={{ ...S.btn(S.surface, S.textDim, `1px solid ${S.surfaceLight}`), flex: 1, fontSize: 11 }}>
                      Cancel
                    </button>
                  </div>
                ) : (
                  <button onClick={() => setCmDeleteTopic(s.topic)}
                    style={{ ...S.btn("transparent", "#a07070", "none"), width: "100%", fontSize: 10, marginTop: 6, padding: "4px 0" }}>
                    Remove topic
                  </button>
                )}
              </div>
            ))}

            {/* Delete all content */}
            {userContent.length > 0 && (
              <div style={{ marginTop: 20 }}>
                {!cmDeleteConfirm ? (
                  <button onClick={() => setCmDeleteConfirm(true)}
                    style={{ ...S.btn("#2a1a1a", "#d4a4a4", "1px solid #4a2a2a"), width: "100%", fontSize: 12 }}>
                    Delete all content ({userContent.length} problems)
                  </button>
                ) : (
                  <div style={{ background: "#3a1a1a", border: "1px solid #5a2a2a", borderRadius: 8, padding: 14 }}>
                    <p style={{ fontSize: 13, color: "#f87171", margin: "0 0 10px 0", fontWeight: 600 }}>
                      Delete all {userContent.length} problem{userContent.length !== 1 ? "s" : ""}? This can't be undone.
                    </p>
                    <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 10px 0" }}>
                      Your study progress will be kept. The starter pack will reload on next launch.
                    </p>
                    <div style={{ display: "flex", gap: 8 }}>
                      <button onClick={handleCmDelete}
                        style={{ ...S.btn("#5a1a1a", "#f87171", "1px solid #7a2a2a"), flex: 1 }}>
                        Yes, delete
                      </button>
                      <button onClick={() => setCmDeleteConfirm(false)}
                        style={{ ...S.btn(S.surface, S.textDim, `1px solid ${S.surfaceLight}`), flex: 1 }}>
                        Cancel
                      </button>
                    </div>
                  </div>
                )}
              </div>
            )}
          </div>
        )}
      </div>
    );
  }

  // ─── EXPORT SCREEN ───────────────────────────────────────────────────

  if (screen === "export") {
    const lines = exportData.split("\n").length;
    return (
      <div style={S.page}>
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 20 }}>
          <h2 style={{ fontSize: 18, fontWeight: 700, color: S.textBright, margin: 0 }}>Export Backup</h2>
          <button onClick={() => setScreen("home")} style={S.btn("transparent", S.textDim)}>← Back</button>
        </div>

        <p style={{ fontSize: 12, color: S.textDim, margin: "0 0 12px 0", lineHeight: 1.5 }}>
          Copy this JSON and save it somewhere safe. To restore, paste it into the Content Manager.
        </p>

        <button onClick={handleExportCopy}
          style={{ ...S.btnPrimary, marginBottom: 12, fontSize: 13 }}>
          {exportCopied ? "✓ Copied to clipboard" : "Copy to clipboard"}
        </button>

        <textarea
          readOnly
          value={exportData}
          onFocus={e => e.target.select()}
          style={{
            width: "100%", minHeight: 200, maxHeight: 400, background: S.surface, color: S.textDim,
            border: `1px solid ${S.surfaceLight}`, borderRadius: 8, padding: 14,
            fontSize: 11, fontFamily: "'IBM Plex Mono', monospace", resize: "vertical",
            lineHeight: 1.4, boxSizing: "border-box"
          }}
        />

        <p style={{ fontSize: 10, color: S.textDim, marginTop: 8, ...S.mono }}>
          {lines} lines • {exportData.length.toLocaleString()} chars • {dayKey()}
        </p>
      </div>
    );
  }

  // ─── SETTINGS SCREEN ─────────────────────────────────────────────────

  if (screen === "settings") {
    const handleSaveSettings = async () => {
      const trimmedKey = settingsInput.apiKey.trim();
      const trimmedProxy = settingsInput.proxyUrl.trim();
      setApiKey(trimmedKey);
      setProxyUrl(trimmedProxy);
      await storage.save(STORAGE_KEYS.SETTINGS, { apiKey: trimmedKey, proxyUrl: trimmedProxy });
      setSettingsSaved(true);
      setTimeout(() => setSettingsSaved(false), 2000);
    };

    const handleClearSettings = async () => {
      setApiKey("");
      setProxyUrl("");
      setSettingsInput({ apiKey: "", proxyUrl: "" });
      await storage.save(STORAGE_KEYS.SETTINGS, {});
      setSettingsSaved(true);
      setTimeout(() => setSettingsSaved(false), 2000);
    };

    const masked = settingsInput.apiKey
      ? settingsInput.apiKey.substring(0, 8) + "••••••••" + settingsInput.apiKey.slice(-4)
      : "";

    return (
      <div style={S.page}>
        <div style={{ display: "flex", justifyContent: "space-between", alignItems: "center", marginBottom: 20 }}>
          <h2 style={{ fontSize: 18, fontWeight: 700, color: S.textBright, margin: 0 }}>Settings</h2>
          <button onClick={() => setScreen("home")} style={S.btn("transparent", S.textDim)}>← Back</button>
        </div>

        {/* API Key */}
        <div style={{ marginBottom: 20 }}>
          <p style={{ fontSize: 11, color: S.textDim, margin: "0 0 8px 0", ...S.mono, textTransform: "uppercase", letterSpacing: "0.05em" }}>
            AI Explanations (optional)
          </p>
          <p style={{ fontSize: 12, color: S.text, margin: "0 0 12px 0", lineHeight: 1.6 }}>
            Add an API key to get AI-powered explanations. Without one, the Explain button shows the static explanation built into each problem. Your key is stored only on this device.
          </p>

          <label style={{ fontSize: 11, color: S.textDim, display: "block", marginBottom: 4, ...S.mono }}>API Key</label>
          <input
            type="password"
            value={settingsInput.apiKey}
            onChange={e => setSettingsInput(s => ({ ...s, apiKey: e.target.value }))}
            placeholder="sk-ant-api03-..."
            style={{
              width: "100%", background: S.surface, color: S.textBright,
              border: `1px solid ${S.surfaceLight}`, borderRadius: 8, padding: "10px 14px",
              fontSize: 13, fontFamily: "'IBM Plex Mono', monospace", boxSizing: "border-box",
              marginBottom: 12
            }}
          />

          <label style={{ fontSize: 11, color: S.textDim, display: "block", marginBottom: 4, ...S.mono }}>Proxy URL</label>
          <input
            type="url"
            value={settingsInput.proxyUrl}
            onChange={e => setSettingsInput(s => ({ ...s, proxyUrl: e.target.value }))}
            placeholder="https://your-worker.your-subdomain.workers.dev"
            style={{
              width: "100%", background: S.surface, color: S.textBright,
              border: `1px solid ${S.surfaceLight}`, borderRadius: 8, padding: "10px 14px",
              fontSize: 13, fontFamily: "'IBM Plex Mono', monospace", boxSizing: "border-box",
              marginBottom: 6
            }}
          />
          <p style={{ fontSize: 10, color: S.textDim, margin: "0 0 16px 0", lineHeight: 1.5 }}>
            Browsers can't call the Anthropic API directly. You need a small proxy (e.g. a free Cloudflare Worker) that forwards requests. The proxy receives your key + the problem text and sends it to Anthropic.
          </p>

          <div style={{ display: "flex", gap: 8 }}>
            <button onClick={handleSaveSettings}
              style={{ ...S.btnPrimary, flex: 1, fontSize: 13 }}>
              {settingsSaved ? "✓ Saved" : "Save"}
            </button>
            {(apiKey || settingsInput.apiKey) && (
              <button onClick={handleClearSettings}
                style={{ ...S.btn("#2a1a1a", "#d4a4a4", "1px solid #4a2a2a"), flex: 1, fontSize: 13 }}>
                Clear
              </button>
            )}
          </div>
        </div>

        {/* Status indicator */}
        <div style={{
          background: apiKey && proxyUrl ? "#1a3a2a" : S.surface,
          border: `1px solid ${apiKey && proxyUrl ? S.accentDim : S.surfaceLight}`,
          borderRadius: 8, padding: 12, marginTop: 8
        }}>
          <p style={{ fontSize: 12, color: apiKey && proxyUrl ? S.accent : S.textDim, margin: 0 }}>
            {apiKey && proxyUrl
              ? "✓ AI explanations enabled — Explain button will call your API."
              : "○ No API configured — Explain button shows static explanations."}
          </p>
        </div>
      </div>
    );
  }

  return null;
}

ReactDOM.createRoot(document.getElementById("root")).render(<OATEngine />);
